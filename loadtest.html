RSVP load test

Runs real requests against the live site with the test guests below, to check it copes when many people reply at once. Sign-in tests only read. The sending test writes test replies; clean up afterwards.

1 · Sign-in, all at once

Every test guest checks their name and code at the same moment, like a burst right after invites go out.

2 · Sign-in, one after another

The same guests, one at a time — compare with test 1 to see how much a crowd slows each person down.

3 · Tricky cases

Wrong code, wrong name, odd capitals/spaces, and the same guest signing in twice at the same moment. Each line says what should happen.

4 · Sending replies, all at once (writes to the sheet)

Every test guest sends an RSVP (yes to everything) at the same moment, and one guest double-sends at the same moment — that guest must be saved exactly once. Needs the admin PIN so the replies can be cleaned up.
